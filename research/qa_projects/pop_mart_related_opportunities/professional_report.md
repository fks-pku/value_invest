# 泡泡玛特相关公司投资机会研究

生成时间：2026-05-29T00:00:00+08:00

## 当前研究目标

当前判断：泡泡玛特相关机会不是“盲盒玩具”单点，而是中国原创角色 IP 全球化、情绪消费、渠道稀缺发售、授权/内容化和供应链承接的组合。最强主线仍是拥有原创 IP 与全球 DTC 渠道的泡泡玛特；第二层是 Sanrio、名创/TOP TOY、布鲁可等相邻 IP/渠道标的；供应链标的更多是订单线索而非价值捕获核心。最大不确定性是 Labubu/THE MONSTERS 热度是否能转化为多 IP 组合与海外复购，而不是一次性潮流周期。

## 问题下钻

### Q1 需求真实度：泡泡玛特热度是否代表一个可持续的 IP 消费赛道？

需求是真的，但不能直接线性外推。泡泡玛特 2025 年收入和利润爆发，海外区域尤其美洲/欧洲增长极强；名创 TOP TOY、布鲁可、Sanrio、Bandai 等也证明角色 IP 和潮玩/爱好消费有扩散性。反面样本是 Funko 和 Mattel 内部分化，说明收藏玩具热潮若没有持续 IP 管理和渠道纪律，会快速转为库存、折扣和利润压力。

泡泡玛特 2025 年收入、毛利、经营利润和调整净利同时高增，是最强一手证据；但 THE MONSTERS 单一 IP 收入占 38.1%，说明增长质量必须看新 IP 接力和海外复购。

### Q1.1.1 泡泡玛特 2025-2026 的数字证明了什么？

事实：2025 年收入 RMB37.120B，同比+184.7%；归母利润 RMB12.776B，同比+308.8%；THE MONSTERS 收入 RMB14.161B，占 38.1%；plush toys 收入 RMB18.708B，占 50.4%，同比+560.6%。2026Q1 媒体引用业务更新称整体收入同比+75%-80%。

推理：泡泡玛特的需求已经从盲盒扩展到毛绒、挂件、社交展示和海外零售，收入不是小基数概念炒作。

判断：需求真实度强，但判断必须折扣单一 IP 集中和海外持续性。若新 IP 和海外复购接不上，2025 的高利润可能被市场当作峰值。

缺口：缺少 2026H1 分 IP、同店、会员复购和渠道库存。

触发器：THE MONSTERS 占比下降但总收入仍高增是正触发；海外收入环比/同店连续走弱或毛利率下滑是负触发。

### Q1.2.1 名创、布鲁可、Sanrio、Bandai、Funko/Mattel 给出什么边界？

事实：TOP TOY 2025 年收入 RMB1.916B，同比+94.8%；布鲁可 2025 年收入 RMB2.913B，同比+30.0%且扭亏；Sanrio TTM/FY 数据高增；Funko 2025 年销售下降并亏损，Mattel Dolls 下滑、Vehicles 增长。

推理：角色 IP/潮玩/爱好消费是真赛道，但公司间的 value capture 差异很大：原创角色和授权生态优于单纯 OEM，成熟 IP 组合优于单一热款。

判断：相关公司应分层，而不是一篮子买主题：原创 IP 平台优先，其次多 IP 授权和渠道平台，供应链/授权收藏玩具只是线索。

缺口：缺少可比口径下的会员复购、IP 集中度、库存周转和广告/渠道费用。

触发器：若相邻公司在收入增长同时毛利/现金流转弱，应说明主题扩散没有形成利润捕获。

### Q2 价值捕获瓶颈：谁能把 IP 热度转成利润？

价值捕获主要来自五个节点：原创 IP 运营、全球 DTC/零售渠道、授权 IP/标准化产品系统、毛绒/手办供应链、内容化与授权。评分最高的是原创 IP 运营，因为它同时控制角色心智、稀缺发售、产品定价和粉丝复购；供应链虽然受益订单，但毛利率和客户集中度显示议价权弱。

证据：[ev_pop_2025_ip_region_mix](https://www.hkexnews.hk/listedco/listconews/sehk/2026/0325/2026032500285.pdf)，[ev_pop_2025_product_mix](https://www.hkexnews.hk/listedco/listconews/sehk/2026/0325/2026032500285.pdf)，[ev_dream_2025_annual](https://www.hkexnews.hk/listedco/listconews/sehk/2026/0408/2026040802047.pdf)，[ev_miniso_2025_annual](https://filecache.investorroom.com/mr5ir_miniso/368/Annual%20Report%202025%20HK.pdf)，[ev_bloks_2025_annual](https://www.hkexnews.hk/listedco/listconews/sehk/2026/0327/2026032701144.pdf)，[ev_pop_sony_labubu_film](https://www.reuters.com/business/media-telecom/sony-develop-labubu-feature-film-deadline-reports-2026-05-09/)

### Q2.1 原创 IP、渠道和供应链分别有什么瓶颈属性？

原创 IP 与 DTC 渠道是高分节点；供应链是低分节点。泡泡玛特高毛利和 THE MONSTERS 外溢证明它不是普通玩具零售，Dream International 毛利率下行说明 OEM 很难保留主要利润池。

证据：[ev_pop_2025_annual_results](https://www.hkexnews.hk/listedco/listconews/sehk/2026/0325/2026032500285.pdf)，[ev_pop_2025_product_mix](https://www.hkexnews.hk/listedco/listconews/sehk/2026/0325/2026032500285.pdf)，[ev_dream_2025_annual](https://www.hkexnews.hk/listedco/listconews/sehk/2026/0408/2026040802047.pdf)，[ev_miniso_2025_annual](https://filecache.investorroom.com/mr5ir_miniso/368/Annual%20Report%202025%20HK.pdf)

### Q2.1.1 原创 IP 运营为什么是最高价值节点？

事实：THE MONSTERS 单一 IP 2025 年收入 RMB14.161B，占 38.1%；泡泡玛特毛利率约 72.1%；Sanrio 多角色授权高利润增长；Funko 则在授权收藏玩具退潮时销售下降并亏损。

推理：原创 IP 的价值在于控制角色、审美、社区、稀缺发售和产品延展，不是单纯卖玩具。

判断：原创 IP 是最高价值节点，但单一 IP 占比越高，生命周期风险越大。强结论需要看到新 IP 接力和海外复购。

缺口：各 IP 的复购、会员重合度、二级市场溢价和生命周期长度缺失。

触发器：新 IP 收入占比上升且毛利稳定则强化；THE MONSTERS 退潮拖累总收入则降级。

证据：[ev_pop_2025_ip_region_mix](https://www.hkexnews.hk/listedco/listconews/sehk/2026/0325/2026032500285.pdf)，[ev_sanrio_financial_snapshot](https://stockanalysis.com/quote/tyo/8136/financials/)，[ev_funko_2025_results](https://investor.funko.com/news-and-events/press-releases/Press-Releases/2026/Funko-Reports-2025-Fourth-Quarter-Full-Year-Financial-Results-Provides-Full-Year-Outlook-for-2026/default.aspx)

### Q2.1.2 毛绒和手办供应链能否捕获主要利润？

事实：泡泡玛特 plush toys 2025 年收入 RMB18.708B，同比+560.6%；Dream plush stuffed toys 收入 HK$3.264B，同比+18.0%，但公司毛利率从 23.0% 降至 20.2%，四个客户各占收入超过 10%。

推理：供应链能受益订单，但毛利和客户集中显示议价权弱，容易被品牌方和大客户压价。

判断：供应链是跟踪线索，不是最高价值捕获节点。除非出现产能稀缺、独家工艺或客户结构改善，否则观察强度低于 IP 平台。

缺口：缺少 Dream 与泡泡玛特直接客户关系、订单占比和分客户利润率。

触发器：若毛利率回升且客户集中下降，供应链强度上调；反之只保留 lead。

证据：[ev_pop_2025_product_mix](https://www.hkexnews.hk/listedco/listconews/sehk/2026/0325/2026032500285.pdf)，[ev_dream_2025_annual](https://www.hkexnews.hk/listedco/listconews/sehk/2026/0408/2026040802047.pdf)

### Q2.1.3 全球零售渠道是否构成瓶颈？

事实：TOP TOY 2025 年收入同比+94.8%；泡泡玛特美洲/欧洲 2025 年高增；但 2026Q1 媒体指出海外业务虽同比快增、环比转弱。

推理：渠道触达是 IP 全球化的必要条件，但渠道本身不能替代原创 IP。名创强在门店网络，弱在 IP 控制。

判断：渠道是中高分节点。MINISO/TOP TOY 值得观察，但强度应低于泡泡玛特和 Sanrio 这类 IP 控制方。

缺口：缺少 TOP TOY 单独同店、海外占比和自有 IP 收入。

触发器：TOP TOY 继续高增且自有 IP 占比提升则上调；若只靠渠道流量则维持中性。

证据：[ev_miniso_2025_annual](https://filecache.investorroom.com/mr5ir_miniso/368/Annual%20Report%202025%20HK.pdf)，[ev_miniso_q1_2026](https://ir.miniso.com/news-releases/news-release-details/miniso-announces-march-quarter-2026-unaudited-financial-results)，[ev_pop_q1_2026_update](https://www.scmp.com/business/china-business/article/3310251/pop-marts-overseas-revenue-falls-despite-labubu-craze-amid-us-china-trade-war)

### Q2.1.4 授权 IP 和标准化玩具系统是否能替代原创 IP？

事实：布鲁可 2025 年收入 RMB2.913B，同比+30.0%，adjusted profit RMB674.9M；拥有近 550 个专利组合和 Bloks System；Bandai Namco 是成熟 IP 协同平台。

推理：授权 IP + 产品系统能降低单一原创 IP 失败风险，但授权方和渠道方分走利润，价值捕获通常低于原创 IP 所有人。

判断：布鲁可是第二层验证型机会；Bandai 是成熟对照和分散标的，不是泡泡玛特主题的直接高弹性标的。

缺口：缺少授权费率、核心 IP 到期和自有 IP 占比。

触发器：自有系统/IP 占比提升是上调信号；授权成本上行或核心 IP 到期是降级信号。

证据：[ev_bloks_2025_annual](https://www.hkexnews.hk/listedco/listconews/sehk/2026/0327/2026032701144.pdf)，[ev_bandai_ip_synergy](https://www.bandainamco.co.jp/en/ir/library/result.html)

### Q2.2 内容化和授权能否打开第二增长曲线？

内容化是可选增量，不是当前估值的主证据。Sony/Labubu 电影线索说明泡泡玛特想从玩具 IP 走向内容 IP，但影视项目成功率和财务贡献都需要等实际立项、上映、授权和衍生品反馈。

证据：[ev_pop_sony_labubu_film](https://www.reuters.com/business/media-telecom/sony-develop-labubu-feature-film-deadline-reports-2026-05-09/)，[ev_sanrio_financial_snapshot](https://stockanalysis.com/quote/tyo/8136/financials/)，[ev_bandai_ip_synergy](https://www.bandainamco.co.jp/en/ir/library/result.html)

### Q2.2.1 Labubu 影视化/授权化能否改变估值框架？

事实：媒体报道称 Sony 开发 Labubu 电影。Sanrio 和 Bandai 证明成熟角色 IP 可跨授权、内容、商品和娱乐，但它们用了长期 IP 组合和内容生态。

推理：如果内容化成功，泡泡玛特可降低单品玩具周期风险；但影视化从新闻到利润兑现存在长链条。

判断：目前只能作为看涨期权，不能作为核心投资证据。核心仍是角色商品化和复购数据。

缺口：没有官方项目公告、上映计划、投资金额、授权收入和衍生品预期。

触发器：官方确认项目、内容上线、授权商品收入披露是上调；项目搁置或口碑失败则不计入估值。

证据：[ev_pop_sony_labubu_film](https://www.reuters.com/business/media-telecom/sony-develop-labubu-feature-film-deadline-reports-2026-05-09/)，[ev_sanrio_financial_snapshot](https://stockanalysis.com/quote/tyo/8136/financials/)，[ev_bandai_ip_synergy](https://www.bandainamco.co.jp/en/ir/library/result.html)

### Q3 反证与赔率：哪些风险会证伪泡泡玛特相关机会？

最关键的风险不是“热度下降”四个字，而是可量化为四类反证：单一 IP 集中、海外复购不足、盗版/仿品和贸易摩擦、估值对峰值利润的折价或错误定价。Funko 是反面样本；Dream 毛利下行说明供应链不能自动分享高景气。

### Q3.1 基本面反证：热度、海外、盗版和库存如何降级？

### Q3.1.1 Labubu/THE MONSTERS 集中度是否会变成反证？

事实：THE MONSTERS 2025 年收入占泡泡玛特总收入 38.1%；Funko 2025 年销售下降并亏损；Mattel Dolls 下滑而 Vehicles 增长。

推理：单一角色爆发既证明 IP 运营能力，也提高未来比较基数和生命周期风险。

判断：如果新 IP 接力成功，Labubu 是平台验证；如果接力失败，它就是周期峰值风险。

缺口：缺少各 IP 2026Q1/Q2 的收入占比、复购和用户重合。

触发器：THE MONSTERS 占比降而总收入不降是平台化正证据；占比升且总增速放缓是负证据。
