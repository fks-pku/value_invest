# 存储行业投资机会 QA 问题设计 V2

这份文件是问题设计预览，用于审计新的存储行业 playbook。它不是最终研究报告，也不代表这些问题已经完成证据收集。

## Q1 需求：AI、数据中心和终端需求如何转化为可持续的 bit、ASP 与产品 mix？

### Q1.1 工作负载到产品需求的传导链

- Q1.1.1 AI 加速器平台的 HBM 容量/带宽强度是否继续上升，并如何传导到 HBM bit demand 和 mix？
- Q1.1.2 推理、RAG、Agent 和数据湖是否拉动 eSSD、NAND 与 nearline HDD 的新增容量，而不只是库存回补？
- Q1.1.3 PC、手机、消费电子和通用服务器需求会不会稀释 AI 存储主线？

### Q1.2 price / volume / mix / inventory 增长质量

- Q1.2.1 当前收入和利润增长分别由 bit shipment、ASP、产品 mix、利用率还是库存回补驱动？
- Q1.2.2 合约价、现货价、库存天数和客户预付款是否支持需求持续性？

### Q1.3 需求斜率与供给斜率错配

- Q1.3.1 AI/HBM/eSSD 需求斜率是否明显高于行业 bit supply、wafer starts 和产能转换斜率？
- Q1.3.2 客户 capex、RPO/backlog、GPU/ASIC 订单和服务器交付是否共同确认需求持续？

## Q2 价值捕获：哪些存储环节具备稀缺性、定价权和财务转化能力？
