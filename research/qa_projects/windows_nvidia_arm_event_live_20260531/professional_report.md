# Windows 接入 NVIDIA Arm 芯片事件投资机会研究

报告日期：2026-05-31

## 当前研究目标

评估 Windows + NVIDIA Arm PC 平台事件是否形成未被充分定价的稀缺投资机会。

## 最终标的推荐

| 排名 | 标的 | Action State | 总分 | 理由 |
|---|---|---:|---:|---|
| 1 | NVDA | watch_only | 3.37 | NVIDIA 具备 AI/GPU 平台稀缺性，若进入 Windows 主处理器层，战略价值较高；但 PC SoC 对整体财务弹性和当前估值未被低估都未证明。 |
| 2 | MSFT | watch_only | 3.38 | Microsoft 控制 Windows 生态和兼容性门槛，是最稳的战略受益者；但单一芯片事件对其收入弹性有限，估值也很难证明低估。 |
| 3 | 2454.TW | watch_only | 3.18 | 若 MediaTek 是实际协作方，它可能比大市值平台股更有业绩弹性；但公开证据仍不足，必须以本地上市标的保留但封顶。 |
| 4 | ARM | watch_only | 3.25 | Arm 是最清晰的 IP 层稀缺节点，Windows Arm 出货扩大有 royalty 弹性；但当前估值和单机 royalty 敏感性需要严格验证。 |
| 5 | QCOM | watch_only | 3.23 | Qualcomm 既受益于 Windows Arm 生态被验证，也面临 NVIDIA 进入后先发溢价被稀释的风险。 |

| 7 | DELL | no_action | 2.69 | Dell 可能是首批展示 OEM，但整机通道稀缺性较低，利润率和差异化不如平台/IP 层。 |
| 8 | INTC | no_action | 2.64 | Intel 是 PC 链重要玩家，但该事件更偏竞争风险，不构成稀缺低估机会。 |
